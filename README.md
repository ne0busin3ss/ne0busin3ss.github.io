# Artificial Intelligence Research

Research notes and tools by David Philip Raymond, published with GitHub Pages at
<https://ne0busin3ss.github.io> and linked from [dave-raymond.com](https://dave-raymond.com).
The common thread is AI: how it is built, what it costs, and the tools it can build.
